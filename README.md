# Carpooling-Application
C++ Carpooling Application developed with OOP principles. Features class inheritance, encapsulation, and dynamic memory management to simulate a real-world ride-sharing platform with user authentication and payment processing.

* **Core OOP Concepts:** Demonstrates inheritance, encapsulation, polymorphism, and composition.
* **Class Architecture:** Structured with multiple interacting classes: `User`, `Driver`, `Passenger`, `Vehicle`, `Ride`, `Booking`, and `Payment`.
* **Memory Management:** Utilizes dynamic memory management using pointers and ensures robustness through error handling.
* **System Logic:** Supports user authentication, ride creation, booking management, and dynamic payment validation.

The `User` class serves as a base class, while `Driver` and `Passenger` extend its functionality through inheritance. Relationships between objects are managed through composition and association, allowing a realistic representation of system interactions.
